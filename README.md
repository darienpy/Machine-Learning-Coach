
# Machine Learning Coach

A Python application designed to help business analytics students review tabular datasets before beginning classification modeling.

## Project Overview

Machine Learning Coach is a browser-based application built using Python and Streamlit. It will help users identify common data quality issues and understand how those issues may affect machine learning projects.

## Planned Core Features

1. Upload and preview CSV datasets.
2. Identify missing values and other data quality issues.
3. Select and validate a target column for classification.
4. Provide explanations and recommendations for preparing datasets.
5. Export a dataset preparation checklist.

## Technologies

- Python 3.14.7
- Streamlit
- pandas
- Git and GitHub
- Visual Studio Code

## Installation

Create and activate a Python virtual environment:

    python3 -m venv .venv
    source .venv/bin/activate

Install dependencies:

    python -m pip install -r requirements.txt

## Running the Application

Launch the application using:

    python -m streamlit run app.py

Open the local URL displayed in the terminal.
